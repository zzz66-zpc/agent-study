## 二、从零到能用的 8 个动作

```powershell
# 1. 装 Python 3.12.10（python.org，勾 Add python.exe to PATH）
# 2. 装 Git（默认编辑器选 VS Code，初始分支 main）
# 3. 装 VS Code + Python 扩展
# 4. 建目录并初始化仓库
mkdir C:\Users\<你的用户名>\code\agent-study
cd C:\Users\<你的用户名>\code\agent-study
git init

# 5. 建项目级虚拟环境
py -3.12 -m venv .venv
.venv\Scripts\python.exe --version      # 应输出 Python 3.12.10

# 6. 写并运行第一个程序（hello.py 见下）

# 7. 写 .gitignore
#    .venv/  __pycache__/  *.pyc  .env

# 8. 首次提交
git add .
git commit -m "第一个程序：hello.py"
```

`hello.py`：

```python
name = input("你叫什么名字？")
print(f"你好，{name}！这是我写的第一行 Python。")
```

一次性的 Git 配置：

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
git config --global init.defaultBranch main
git config --global core.quotepath false      # 中文文件名不显示成八进制
```

## 三、9 个坑（复现时可直接规避）

| # | 坑 | 现象 | 解法 |
|---|---|---|---|
| 1 | 两个 Python 共存 | `python` 指向 3.14，`py -0` 里 3.14 带 `*` | 项目级 `.venv` 隔离，不改系统默认 |
| 2 | `uv` 装了但命令不认 | `uv venv` 报「无法识别 uv」 | 改用标准库 `venv`；装包用 `py -3.12 -m pip` |
| 3 | 多行命令被粘成一行 | `--version+py -0` → `Unknown option` | 一次只粘一行，回车看输出再粘下一条 |
| 4 | 粘贴内容被程序当成输入 | 名字变成 `git add .git commit -m ...` | 程序等输入时**只用手打** |
| 5 | 把文件内容敲进终端 | `__pycache__/` 报「无法识别」 | `.gitignore` 是文件，要在编辑器里写 |
| 6 | 脚本中文乱码 | 输出 `浠?鎴叏灞?...` | PowerShell 脚本存 **UTF-8 with BOM** |
| 7 | `Add-Type` 重复注册 | 第二次运行报 `TYPE_ALREADY_EXISTS` | 注册前判断 `-not ("X" -as [type])` |
| 8 | 截图分辨率低于屏幕 | 屏幕 2560×1600，截图只有 1707×1067 | 采集前调 `SetProcessDpiAwareness(2)` |
| 9 | 截图混入提示文字 | 图里出现「1 秒后截图…」 | 倒计时改静默，只响提示音不打印 |

## 六、复盘：下次可以更省时
