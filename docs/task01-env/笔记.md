## 三、遇到的问题与解决

### 1. 系统里有两个 Python，默认指向 3.14

- **现象**：`py -0` 显示 `-V:3.14 *` 与 `-V:3.12`，直接敲 `python hello.py` 走的是 `AppData\Local\Programs\Python\Python314\python.exe`
- **原因**：电脑上原本装着 Python 3.14（随 VS 2026 安装），带 `*` 的是 py 启动器的默认版本
- **解决**：不卸载系统版本，改为**项目级隔离**——`py -3.12 -m venv .venv`，VS Code 选 `.venv`，此后项目内一律是 3.12.10
- **结论**：解释器版本问题应该在项目层解决，而不是改系统默认

### 2. uv 安装后命令不可用

- **现象**：`uv venv --python 3.12` 报「无法将 uv 项识别为 cmdlet」，`.venv` 因此没被创建，后续 `.venv\Scripts\python.exe` 也报「无法加载模块 .venv」
- **原因**：`uv` 未成功安装/未进 PATH；第二条报错是第一条的连锁反应
- **解决**：改用 Python 标准库自带的 `venv`（`py -3.12 -m venv .venv`），装包用 `py -3.12 -m pip`
- **结论**：先让链路跑通，工具可以后补；`venv` 是标准库，永远可用

### 3. PowerShell 里粘贴多行命令被拼成一行

- **现象**：`.venv\Scripts\python.exe --version.venv\Scripts\python.exe hello.py` → `unknown option: --version.venv...`
- **原因**：把 `.gitignore` 的文件内容和多条命令一次性粘进了终端，终端不会按换行拆分粘贴内容
- **解决**：**一次粘一行，回车看到输出再粘下一行**；`.gitignore` 这类文件内容要写进文件，不能在终端执行

### 4. 截图脚本中文乱码

- **现象**：脚本输出的中文变成 `浠?鎴叏灞?...`
- **原因**：脚本保存为「UTF-8 无 BOM」，Windows PowerShell 5.1 按 GBK 解析
- **解决**：另存为 **UTF-8 with BOM**（`EF BB BF`），乱码消失

## 五、从零复现步骤（约 3 分钟）

```powershell
# 1. 克隆或新建目录
mkdir C:\Users\<你的用户名>\code\agent-study
cd C:\Users\<你的用户名>\code\agent-study

# 2. 建虚拟环境（需已安装 Python 3.12）
py -3.12 -m venv .venv
.venv\Scripts\python.exe --version      # 应输出 Python 3.12.10

# 3. 运行程序
.venv\Scripts\python.exe hello.py

# 4. 装第三方库的方式（本任务暂未用到）
py -3.12 -m pip install <包名>
```

依赖清单：目前**无第三方依赖**，仅使用标准库；Python 要求 `>=3.11`。
